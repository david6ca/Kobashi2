ModelBridge

Подключайте Claude Code, Codex и GitHub Copilot к выбранному источнику. Управляйте аккаунтами, переключайте источники и настраивайте клиентов в одном нативном окне.

Требуется macOS 13 или новее. Для локальных моделей нужен Mac с Apple Silicon, macOS 15 или новее, достаточно памяти и места, а также первоначальная загрузка. Локальная работа не требует подписки Copilot. Режим GitHub Copilot требует подходящего аккаунта и использует его лимит; запросы обрабатывают GitHub Copilot и поставщики моделей. Клиенты устанавливаются отдельно. ModelBridge — независимый продукт.

Вопросы: support@pomegram.com. Хранение и удаление данных у поставщиков регулируются их политиками.

ローカルモデルの推論は Mac 上で行われます。モデルと実行環境のダウンロードは GitHub、Microsoft のパッケージサービス、Hugging Face に接続しますが、プロンプトやコードは添付しません。クライアント、プラグイン、ツールは独自に通信する場合があります。

GitHub Copilot を選ぶと、会話、コード、画像、ツール結果を含むリクエストが GitHub Copilot とモデル提供者に送信され、各社のポリシーとアカウント設定が適用されます。ModelBridge は独立した製品です。

アカウント、認証情報、設定、設定のバックアップ、モデルは端末に保存されます。認証情報はローカルファイルに保存され、Keychain 保護やアプリ独自の暗号化を保証しません。診断・設定ログには技術情報とエラーが含まれます。共有前に確認してください。

アカウントを削除すると ModelBridge の保存済み認証情報が削除されます。GitHub アカウントや提供者のデータは削除されません。ログやモデルは残る場合があります。ローカルデータを手動で削除する前に ModelBridge を終了し、クライアント設定を復元してください。

お問い合わせ：support@pomegram.com。提供者のデータ保持と削除には各社のポリシーが適用されます。

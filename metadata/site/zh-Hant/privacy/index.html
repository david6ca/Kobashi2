隱私聲明 · 2026 年 11 月 11 日

本機模型在 Mac 上完成推理。模型與執行環境下載會連接 GitHub、Microsoft 套件服務和 Hugging Face，不附帶 prompts 或程式碼。用戶端、外掛和工具可能自行連網。

選擇 GitHub Copilot 後，請求及其包含的對話、程式碼、影像和工具結果會傳送至 GitHub Copilot 及其模型服務商，並遵循其政策和帳號設定。ModelBridge 是獨立產品。

帳號、憑據、設定、設定備份和下載模型儲存在裝置上。憑據儲存在本機檔案中；ModelBridge 不宣稱使用 Keychain 或應用層加密。本機診斷和安裝記錄包含技術詳情與錯誤，分享前請檢查。

移除帳號會從 ModelBridge 刪除該帳號的已儲存憑據，不會刪除 GitHub 帳號或服務商持有的資料。記錄和下載模型可能保留。手動刪除本機資料前請先結束 ModelBridge，以還原受管理的用戶端設定。

隱私問題：support@pomegram.com。服務商的資料保留與刪除遵循其政策。

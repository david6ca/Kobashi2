Les modèles locaux traitent les requêtes sur votre Mac. Les téléchargements des modèles et de leur environnement contactent GitHub, les services de paquets Microsoft et Hugging Face, sans joindre vos prompts ou votre code. Les clients, extensions et outils peuvent effectuer leurs propres requêtes réseau.

Si vous sélectionnez GitHub Copilot, les requêtes et les conversations, le code, les images et les résultats d’outils qu’elles contiennent sont transmis à GitHub Copilot et à ses fournisseurs de modèles, selon leurs politiques et vos réglages. ModelBridge est un produit indépendant.

Les comptes, identifiants, réglages, sauvegardes de configuration et modèles sont stockés sur votre appareil. Les identifiants sont enregistrés dans des fichiers locaux ; aucune protection par Trousseau ou chiffrement applicatif n’est revendiquée. Les journaux locaux de diagnostic et d’installation contiennent des détails techniques et des erreurs. Vérifiez-les avant de les partager.

Retirer un compte supprime ses identifiants enregistrés dans ModelBridge, mais pas votre compte GitHub ni les données détenues par les fournisseurs. Les journaux et modèles peuvent rester. Quittez ModelBridge avant de supprimer ses données locales pour restaurer les réglages clients gérés.

Questions : support@pomegram.com. La conservation et la suppression chez les fournisseurs relèvent de leurs politiques.

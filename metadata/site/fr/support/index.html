Connectez Claude Code, Codex et GitHub Copilot à la source de votre choix. Gérez les comptes, changez de source et contrôlez chaque client dans une fenêtre native.

Nécessite macOS 13 ou ultérieur. Les modèles locaux exigent un Mac Apple Silicon avec macOS 15 ou ultérieur, assez de mémoire et de stockage, et un téléchargement initial. Aucun abonnement Copilot n’est nécessaire en local. Le mode GitHub Copilot exige un compte éligible et utilise son quota ; GitHub Copilot et ses fournisseurs traitent les requêtes. Les clients s’installent séparément. ModelBridge est indépendant.

Questions : support@pomegram.com. La conservation et la suppression chez les fournisseurs relèvent de leurs politiques.

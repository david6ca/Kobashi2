ModelBridge

Conecta Claude Code, Codex y GitHub Copilot a la fuente que elijas. Gestiona cuentas, cambia de fuente y controla cada cliente en una ventana nativa.

Requiere macOS 13 o posterior. Los modelos locales necesitan un Mac con Apple Silicon, macOS 15 o posterior, memoria y espacio suficientes y una descarga inicial. La inferencia local no requiere suscripción a Copilot. El modo GitHub Copilot requiere una cuenta válida y usa su cuota; GitHub Copilot y sus proveedores procesan las solicitudes. Instala los clientes por separado. ModelBridge es independiente.

Consultas: support@pomegram.com. La conservación y eliminación por los proveedores dependen de sus políticas.

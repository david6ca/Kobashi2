개인정보 처리방침 · 2026년 11월 11일

로컬 모델의 추론은 Mac에서 처리됩니다. 모델 및 실행 환경 다운로드 시 GitHub, Microsoft 패키지 서비스, Hugging Face에 연결하지만 프롬프트나 코드는 첨부하지 않습니다. 클라이언트, 플러그인, 도구는 자체적으로 네트워크 요청을 할 수 있습니다.

GitHub Copilot을 선택하면 대화, 코드, 이미지, 도구 결과가 포함된 요청이 GitHub Copilot 및 모델 제공업체로 전송됩니다. 해당 정책과 계정 설정이 적용됩니다. ModelBridge는 독립 제품입니다.

계정, 인증 정보, 설정, 설정 백업, 모델은 기기에 저장됩니다. 인증 정보는 로컬 파일에 저장되며 Keychain 보호나 앱 수준 암호화를 보장하지 않습니다. 로컬 진단 및 설치 로그에는 기술 정보와 오류가 포함됩니다. 공유 전에 검토하세요.

계정 제거는 ModelBridge에 저장된 인증 정보를 삭제하며 GitHub 계정이나 제공업체의 데이터를 삭제하지 않습니다. 로그와 모델은 남을 수 있습니다. 로컬 데이터를 수동 삭제하기 전에 ModelBridge를 종료해 관리 중인 클라이언트 설정을 복원하세요.

개인정보 문의: support@pomegram.com. 제공업체의 데이터 보관 및 삭제에는 해당 정책이 적용됩니다.

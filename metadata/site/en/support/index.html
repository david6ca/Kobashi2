ModelBridge

Connect Claude Code, Codex and GitHub Copilot to a source you choose. Manage saved accounts, switch sources and control each client in one native window.

Requires macOS 13 or later. Local models require an Apple Silicon Mac with macOS 15 or later, enough memory and storage, and an initial download. Local inference needs no Copilot subscription. GitHub Copilot mode requires an eligible account and uses its allowance; requests are processed by GitHub Copilot and its model providers. Clients must be installed separately. ModelBridge is an independent product.

Privacy questions: support@pomegram.com. Provider retention and deletion are governed by the selected provider.

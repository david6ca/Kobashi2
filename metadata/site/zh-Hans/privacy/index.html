隐私声明 · 2026 年 11 月 11 日

本地模型在 Mac 上完成推理。模型与运行环境下载会连接 GitHub、Microsoft 软件包服务和 Hugging Face，不附带 prompts 或代码。客户端、插件和工具可能自行联网。

选择 GitHub Copilot 后，请求及其包含的会话、代码、图像和工具结果会发送至 GitHub Copilot 及其模型服务商，并遵循其政策和账号设置。ModelBridge 是独立产品。

账号、凭据、设置、配置备份和下载模型保存在设备上。凭据保存在本地文件中；ModelBridge 不宣称使用 Keychain 或应用层加密。本地诊断和安装日志记录技术详情与错误，分享前请检查。

移除账号会从 ModelBridge 删除该账号的已保存凭据，不会删除 GitHub 账号或服务商持有的数据。日志和下载模型可能保留。手动删除本地数据前请先退出 ModelBridge，以恢复受管理的客户端配置。

隐私问题：support@pomegram.com。服务商的数据保留与删除遵循其政策。
